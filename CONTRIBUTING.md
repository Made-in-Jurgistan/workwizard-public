WorkWizard is a proprietary project and doesn't accept outside code
contributions. There are other ways to help, and we'd be glad to hear from you.

## Bug Reports

Found a bug? Please [open a GitHub issue](https://github.com/Made-in-Jurgistan/workwizard-public/issues)
with:

1. **Summary**: one-line description of the problem
2. **Steps to reproduce**: numbered list, as specific as possible
3. **Expected behaviour**: what you expected to happen
4. **Actual behaviour**: what happened instead
5. **Environment**: browser, OS, device (if applicable)
6. **Screenshots**: if the issue is visual

## Feature Suggestions

Have an idea? Please [open a GitHub issue](https://github.com/Made-in-Jurgistan/workwizard-public/issues)
with the `enhancement` label and:

1. **Problem**: what educational or usability problem does this solve?
2. **Proposal**: describe the feature at a high level
3. **Alternatives**: any workarounds or alternative approaches you considered
4. **Audience**: who benefits? (teachers, students, specific grade bands)

## Pedagogical Feedback

Parents, teachers (including tutors), students from grade 3 and school leaders can
give feedback through our survey at
[workwizard-demo.vercel.app/survey](https://workwizard-demo.vercel.app/survey).
It is about practising with worksheets in every situation: in class, as homework and
before a test. It asks first how practice goes today, then shows two example
worksheets next to their personalised versions, and asks what you think and whether
you would try it. It takes 2 to 5 minutes, is anonymous, and asks nothing about money.
At the end you can see how others in your role answered and try WorkWizard on a real
worksheet. The current survey version is `v3`.

## What We Cannot Accept

- Pull requests with source code (the codebase is proprietary)
- Contributions that reveal exercise answers or bypass answer protection
- Suggestions that require exposing internal architecture or infrastructure

## Issue Guidelines

- Search existing issues before opening a new one
- One issue per problem or suggestion
- Be respectful and constructive
- Issues that are off-topic or spam will be closed

Thanks for taking the time to help.
